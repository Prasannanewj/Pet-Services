# Long-Term Medication: Product Planning

This is a **separate proposal**, not an approved change to the repository's existing vaccination-focused strategy, backlog, roadmap, or linked GitHub issues. It starts with US owners of dogs taking daily oral chronic medication; the existing plan starts with vaccination for dogs and cats. Their scopes, targets, priorities, and north-star metrics differ and must be reconciled by product, clinical, and business owners before committing to a unified pilot.

All personas, estimates, targets, features, and workflows are hypotheses, not evidence of implemented functionality or Zoetis commitments. Clinical, legal, privacy, safety, and partner review are required before launch.
